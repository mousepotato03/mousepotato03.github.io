Android·Web 개발자

한국항공대 소프트웨어학과 4학년이며, 2025년 9월부터 학교를 다니면서 비틀웍스에서 Android 앱과 PHP 웹을 개발하고 있습니다.

앱과 웹을 함께 다루면서 두 쪽에 걸친 문제를 디버깅한 경험이 많습니다. 문제가 생기면 원인이 어느 쪽에 있는지부터 가려내 고칩니다. 고친 뒤에는 같은 문제가 다시 나타났을 때 원인을 바로 찾을 수 있도록 로그를 남기고 모니터링 도구를 만들어 둡니다.

개인 시간에는 새로 나온 AI 개발 도구를 써 보고, 직접 이것저것 만들어 봅니다. 자주 쓰게 된 오픈소스 도구에는 버그 수정을 기여하기도 했습니다. 그렇게 익힌 하네스 엔지니어링으로 팀의 반복 작업을 자동화한 경험도 있습니다.

기술

Android · PHP · WebView
PHP·WebView로 제공하던 학습 기능을 포함한 주요 기능을 Android 네이티브로 옮기고, WorkManager로 단말에 남은 학습 기록을 재전송했습니다.
CameraX · TFLite · WebRTC
태블릿에서 학생을 감지하고 학습관 관리자에게 실시간 영상을 전송하도록 구현했습니다. 각 기능이 카메라를 사용하는 시점을 한 서비스에서 관리했습니다.
SQL · FCM
딩동 대기방에서 상태가 바뀌지 않는 원인을 DB 쿼리까지 추적했습니다. FCM 메시지는 Android 통화 알림과 연결했습니다.
Flutter · Dart
BLoC과 Riverpod으로 상태를 관리해, 화면과 비즈니스 로직을 분리한 앱을 구성할 수 있습니다.
Python · Claude Code · Figma MCP
Figma 시안을 섹션별로 구현하는 Claude Code 명령을 만들고, Python 스크립트로 작업 상태 확인과 CSS 병합을 자동화했습니다.
