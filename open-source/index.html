#33988병합됨2026.11.12 병합

탭이 가득 찬 창의 드래그 영역 복구

문제와 원인
사이드바를 닫고 탭을 많이 열면 탭 목록이 제목 표시줄의 빈 공간을 모두 차지했습니다. 창을 끌 자리가 사라지는 조건을 재현했습니다.
변경 사항
TabGroupPanel에서 우측 상단에 줄어들지 않는 40px 드래그 영역을 확보했습니다. 모든 탭을 줄이거나 제목 줄을 추가할 때보다 기존 레이아웃에 미치는 범위가 작습니다.
검증
1280×800 창에 탭 14개를 추가한 뒤, 각 픽셀의 드래그 가능 여부를 확인하는 E2E를 추가했습니다. PR에서 기록한 가장 긴 연속 드래그 영역은 수정 전 9px, 수정 후 46px였고 통과 기준은 40px였습니다. Windows 11에서 직접 창을 끌 수 있는지도 확인했습니다.

#41608병합됨2026.11.13 병합

Windows에서 백그라운드 콘솔이 깜빡이는 문제 수정

문제와 원인
Orca를 켜 둔 Windows에서 주기적으로 콘솔 창이 깜빡였습니다. 백그라운드 gh api 호출에서 시작해 gh send-telemetry가 실행하는 tzutil /g까지 프로세스 경로를 추적했습니다.
변경 사항
Orca가 비대화식으로 실행하는 GitHub CLI 자식 프로세스에만 텔레메트리 기본값을 지정했습니다. 사용자가 이미 지정한 환경 변수 값은 유지합니다.
GH_TELEMETRY: env.GH_TELEMETRY ?? 'false',
검증
Windows 11과 gh 2.92.0에서 텔레메트리 샘플링을 강제해 같은 호출을 세 번씩 비교했습니다. 콘솔은 기존 설정에서 3회, 변경 설정에서 0회 나타났습니다. PR의 검증 범위는 자식 프로세스의 A/B 테스트까지이며, 패치된 앱 전체 E2E는 미실행입니다.

#36044열림, 미병합2026.11.21 확인

앱 종료 시 로컬 터미널 세션 정리 옵션

문제와 원인
기존 Orca는 다음 실행에 다시 연결하기 위해 앱 종료 후에도 터미널 세션을 유지합니다. 종료 후에도 에이전트 프로세스가 계속 실행돼, 앱과 함께 세션을 끝내는 옵션을 제안했습니다.
변경 사항
선택 설정을 켜면 일반 종료에서 최종 저장과 추가 쓰기 차단이 성공한 뒤 로컬 PTY를 중단하고 데몬 연결을 해제합니다. 저장 실패 시에는 세션을 유지하고, 업데이트와 재실행은 정리 대상에서 제외합니다.
검증
단위 테스트에서 종료 순서를 확인하고, E2E에서는 앱 종료 후 자식 PID가 사라지는지, 재실행 시 같은 탭 ID로 새 셸이 입력을 받는지 검사합니다. Windows 11 로컬 E2E 통과를 PR에 기록했습니다. 전체 로컬 검사는 완료되지 않았습니다.
